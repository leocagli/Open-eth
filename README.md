# Open-eth

Un repositorio abierto sobre Ethereum / An open repository about Ethereum

## 🇪🇸 Español

### ¿Cómo puedo contribuir con texto?

¡Gracias por tu interés en contribuir! Hay varias formas de agregar texto a este repositorio:

#### Método 1: Pull Request (Recomendado)
1. Haz un fork de este repositorio
2. Clona tu fork: `git clone https://github.com/TU_USUARIO/Open-eth.git`
3. Crea una nueva rama: `git checkout -b mi-contribucion`
4. Edita los archivos o crea nuevos archivos con tu contenido
5. Guarda tus cambios: `git add .` y `git commit -m "Descripción de tu contribución"`
6. Sube tus cambios: `git push origin mi-contribucion`
7. Abre un Pull Request desde GitHub

#### Método 2: Issues
Si prefieres sugerir contenido sin hacer cambios directos:
1. Ve a la pestaña [Issues](https://github.com/leocagli/Open-eth/issues)
2. Haz clic en "New Issue"
3. Describe el contenido que quieres agregar
4. Envía el issue

#### Método 3: Edición directa en GitHub
1. Navega al archivo que quieres editar
2. Haz clic en el ícono del lápiz (✏️) 
3. Realiza tus cambios
4. Describe tus cambios al final de la página
5. Selecciona "Create a new branch for this commit and start a pull request"
6. Haz clic en "Propose changes"

## 🇬🇧 English

### How can I contribute text?

Thank you for your interest in contributing! There are several ways to add text to this repository:

#### Method 1: Pull Request (Recommended)
1. Fork this repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/Open-eth.git`
3. Create a new branch: `git checkout -b my-contribution`
4. Edit existing files or create new files with your content
5. Save your changes: `git add .` and `git commit -m "Description of your contribution"`
6. Push your changes: `git push origin my-contribution`
7. Open a Pull Request from GitHub

#### Method 2: Issues
If you prefer to suggest content without making direct changes:
1. Go to the [Issues](https://github.com/leocagli/Open-eth/issues) tab
2. Click "New Issue"
3. Describe the content you want to add
4. Submit the issue

#### Method 3: Direct Edit on GitHub
1. Navigate to the file you want to edit
2. Click the pencil icon (✏️)
3. Make your changes
4. Describe your changes at the bottom of the page
5. Select "Create a new branch for this commit and start a pull request"
6. Click "Propose changes"

We are looking for contributions about:

- Learning resources
- Development best practices
- Blockchain use cases
- And more...
