# Guía de Contribución / Contributing Guide

## 🇪🇸 Español

### ¡Bienvenido!

Gracias por tu interés en contribuir a Open-eth. Este documento te guiará a través del proceso de contribución.

### ¿Cómo puedo pegar un texto aquí?

Tienes varias opciones para agregar contenido a este repositorio:

#### Opción 1: Edición Directa en GitHub (Más Fácil)

Esta es la forma más sencilla si solo quieres agregar o editar texto:

1. **Editar un archivo existente:**
   - Navega al archivo que quieres editar en GitHub
   - Haz clic en el ícono del lápiz (✏️) en la esquina superior derecha
   - Realiza tus cambios directamente en el editor
   - Desplázate hacia abajo y describe tus cambios
   - Selecciona "Create a new branch for this commit and start a pull request"
   - Haz clic en "Propose changes"

2. **Crear un nuevo archivo:**
   - Navega a la carpeta donde quieres crear el archivo
   - Haz clic en "Add file" > "Create new file"
   - Escribe el nombre del archivo (por ejemplo, `mi-tutorial.md`)
   - Pega o escribe tu contenido
   - Describe tus cambios al final de la página
   - Selecciona "Create a new branch for this commit and start a pull request"
   - Haz clic en "Propose changes"

#### Opción 2: Fork y Pull Request (Recomendado para contribuciones grandes)

Si planeas hacer cambios más significativos:

1. **Haz un Fork:**
   - Haz clic en el botón "Fork" en la esquina superior derecha de GitHub
   - Esto creará una copia del repositorio en tu cuenta

2. **Clona tu Fork:**
   ```bash
   git clone https://github.com/TU_USUARIO/Open-eth.git
   cd Open-eth
   ```

3. **Crea una rama nueva:**
   ```bash
   git checkout -b mi-contribucion
   ```

4. **Realiza tus cambios:**
   - Edita archivos existentes o crea nuevos
   - Puedes usar cualquier editor de texto

5. **Guarda tus cambios:**
   ```bash
   git add .
   git commit -m "Descripción clara de tus cambios"
   ```

6. **Sube tus cambios:**
   ```bash
   git push origin mi-contribucion
   ```

7. **Abre un Pull Request:**
   - Ve a tu fork en GitHub
   - Haz clic en "Compare & pull request"
   - Describe tus cambios y envía el pull request

#### Opción 3: Sugerir Contenido vía Issues

Si tienes una idea pero prefieres no hacer los cambios tú mismo:

1. Ve a la pestaña [Issues](https://github.com/leocagli/Open-eth/issues)
2. Haz clic en "New Issue"
3. Describe el contenido que te gustaría ver agregado
4. Envía el issue

### Formato de Contenido

- **Markdown:** Usamos Markdown para el formato de texto. [Guía de Markdown](https://www.markdownguide.org/basic-syntax/)
- **Idioma:** Puedes contribuir en español, inglés o ambos
- **Organización:** Crea carpetas apropiadas para organizar el contenido (ej: `/tutoriales`, `/contratos-inteligentes`)

### Qué tipo de contenido puedes agregar

- ✅ Tutoriales de Ethereum
- ✅ Explicaciones de conceptos de blockchain
- ✅ Ejemplos de contratos inteligentes
- ✅ Guías de desarrollo
- ✅ Recursos de aprendizaje
- ✅ Mejores prácticas
- ✅ Casos de uso
- ✅ Traducciones de contenido existente

### Código de Conducta

- Sé respetuoso y cortés
- Proporciona información precisa
- Da crédito a las fuentes originales
- No publiques contenido con derechos de autor sin permiso

## 🇬🇧 English

### Welcome!

Thank you for your interest in contributing to Open-eth. This document will guide you through the contribution process.

### How can I paste text here?

You have several options to add content to this repository:

#### Option 1: Direct Edit on GitHub (Easiest)

This is the simplest way if you just want to add or edit text:

1. **Edit an existing file:**
   - Navigate to the file you want to edit on GitHub
   - Click the pencil icon (✏️) in the top right corner
   - Make your changes directly in the editor
   - Scroll down and describe your changes
   - Select "Create a new branch for this commit and start a pull request"
   - Click "Propose changes"

2. **Create a new file:**
   - Navigate to the folder where you want to create the file
   - Click "Add file" > "Create new file"
   - Type the file name (e.g., `my-tutorial.md`)
   - Paste or write your content
   - Describe your changes at the bottom of the page
   - Select "Create a new branch for this commit and start a pull request"
   - Click "Propose changes"

#### Option 2: Fork and Pull Request (Recommended for larger contributions)

If you plan to make more significant changes:

1. **Fork the Repository:**
   - Click the "Fork" button in the top right corner of GitHub
   - This creates a copy of the repository in your account

2. **Clone your Fork:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/Open-eth.git
   cd Open-eth
   ```

3. **Create a new branch:**
   ```bash
   git checkout -b my-contribution
   ```

4. **Make your changes:**
   - Edit existing files or create new ones
   - You can use any text editor

5. **Save your changes:**
   ```bash
   git add .
   git commit -m "Clear description of your changes"
   ```

6. **Push your changes:**
   ```bash
   git push origin my-contribution
   ```

7. **Open a Pull Request:**
   - Go to your fork on GitHub
   - Click "Compare & pull request"
   - Describe your changes and submit the pull request

#### Option 3: Suggest Content via Issues

If you have an idea but prefer not to make the changes yourself:

1. Go to the [Issues](https://github.com/leocagli/Open-eth/issues) tab
2. Click "New Issue"
3. Describe the content you would like to see added
4. Submit the issue

### Content Format

- **Markdown:** We use Markdown for text formatting. [Markdown Guide](https://www.markdownguide.org/basic-syntax/)
- **Language:** You can contribute in Spanish, English, or both
- **Organization:** Create appropriate folders to organize content (e.g., `/tutorials`, `/smart-contracts`)

### What type of content can you add

- ✅ Ethereum tutorials
- ✅ Blockchain concept explanations
- ✅ Smart contract examples
- ✅ Development guides
- ✅ Learning resources
- ✅ Best practices
- ✅ Use cases
- ✅ Translations of existing content

### Code of Conduct

- Be respectful and courteous
- Provide accurate information
- Give credit to original sources
- Don't post copyrighted content without permission
